## 2025-02-20 - Dynamic Accessibility Attributes in Collapsible Sidebars
**Learning:** When building responsive or collapsible sidebars where navigation items transform into icon-only representations, static `aria-label`s are not always optimal. Using conditionally applied `aria-label` and `title` attributes based on the collapsed state (e.g., `isCollapsed ? label : undefined`) ensures screen readers do not announce redundant names when the text is visible, while still providing full context when the element is visually icon-only.
**Action:** When implementing sidebars or menus that collapse into icons, dynamically bind `aria-label` and `title` to the collapsed state. Additionally, always add `aria-hidden="true"` to the decorative icons themselves to prevent screen readers from stumbling over them, and ensure the collapse/expand toggle explicitly sets `aria-expanded` and clear `aria-label`s.
