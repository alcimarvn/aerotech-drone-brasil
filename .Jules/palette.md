## 2026-07-06 - Dynamic ARIA labels for mapped icon links and form accessibility on dark backgrounds
**Learning:** When mapping over objects to render icon-only links (like social media), adding a 'name' property to the data object allows for dynamically generating descriptive 'aria-label' attributes. Additionally, forms without visual labels must use visually hidden '<label>' tags with 'sr-only' and explicitly link to inputs via 'id' / 'htmlFor'. Finally, custom focus ring styling on dark backgrounds requires sufficient offset to be visible (e.g. 'focus-visible:ring-offset-[#0a1a15]').
**Action:** Always include a 'name' or 'label' field in data arrays used for mapping icon-only interactive elements. Use 'sr-only' labels for placeholder-only inputs, and test focus visibility on both light and dark backgrounds to ensure adequate contrast and offsets.
