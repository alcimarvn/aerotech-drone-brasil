## 2024-05-27 - Contextualizing Collapsible UI Elements

**Learning:** When interactive elements (like sidebars or menus) transition between expanded (text + icon) and collapsed (icon-only) states, simply having `aria-expanded` on the container or toggle is insufficient for the nested children. Screen readers and users who rely on visual tooltips lose context if the text is simply hidden using CSS without an alternative text provided to the icon. Furthermore, dark-themed components require explicit focus ring styling because default browser focus indicators often lack sufficient contrast against dark backgrounds.
**Action:** When creating or modifying collapsible UI elements that reduce navigation items to icon-only buttons, dynamically bind `aria-label` (for screen readers) and `title` (for visual tooltips) to the collapsed state to preserve context (e.g., `aria-label={isCollapsed ? "Dashboard" : undefined}`). Additionally, explicitly declare focus visibility via utility classes (e.g., `focus-visible:ring-2 focus-visible:ring-offset-2`) for components situated on dark themes.
