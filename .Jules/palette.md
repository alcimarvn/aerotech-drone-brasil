## 2026-09-19 - Dynamic ARIA Labels in Arrays and Dark Mode Focus Rings
**Learning:** When mapping over arrays to generate interactive icon-only elements (like social links), the data objects often lack a descriptive 'name' property, making it impossible to generate dynamic, meaningful `aria-label`s and `title`s. Furthermore, default browser focus outlines are often invisible against dark background sections (like the dark green footer), and inputs within styled inline forms frequently lack explicitly associated `<label>` tags.
**Action:** Always add a 'name' property to mapped data arrays to fuel accessible dynamic labels. For dark-themed components, explicitly add `outline-none focus-visible:ring-2 focus-visible:ring-emerald-500 focus-visible:ring-offset-2 focus-visible:ring-offset-[#0a1a15]` to override invisible default focus rings. Always ensure form inputs have an associated `<label>`, using `sr-only` if the label should be visually hidden.
