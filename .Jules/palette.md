## 2024-05-24 - Accessible Dynamic Links & Dark Theme Focus Rings
**Learning:** When mapping arrays to render icon-only components (like social media links), storing a `name` property in the data array is a highly effective way to dynamically generate descriptive `aria-label`s. Additionally, on dark-themed components, the default browser focus ring often lacks sufficient contrast. Explicitly applying Tailwind classes like `focus-visible:ring-2 focus-visible:ring-emerald-500 focus-visible:ring-offset-2 focus-visible:ring-offset-[#0a1a15]` is critical to ensure keyboard navigation is visible to users.
**Action:** Always include a `name` or descriptive string property when defining data arrays for icon-only links to populate `aria-label` dynamically. Explicitly define high-contrast focus rings with offsets matching the background color for all interactive elements in dark-themed sections.
