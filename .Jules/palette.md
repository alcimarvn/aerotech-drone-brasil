## 2024-08-08 - Accessible Header Interactions
**Learning:** When interactive elements (like user profile menus) contain text that is visually hidden on smaller screens (`hidden lg:block`), or visual indicator elements (like notification red dots) next to icons, screen readers may announce them redundantly or lose context on mobile. Adding dynamic `aria-label` to the container and explicitly using `aria-hidden="true"` on the inner visible text/decorators ensures a consistent and clean screen reader experience across breakpoints.
**Action:** Always bind the `aria-label` dynamically to the same visible text content (e.g., `aria-label={\`Menu do usuário \${session?.user?.name}\`}`) and apply `aria-hidden="true"` to the inner DOM elements that render that text or purely visual indicators.
