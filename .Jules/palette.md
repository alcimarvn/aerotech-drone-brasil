## 2024-07-26 - Accessible Icon Links & Dark Theme Focus Rings
**Learning:** When mapping over items to render icon-only links or buttons, conditionally rendered labels or statically assigning them can be rigid. Additionally, default browser focus rings often lack contrast against very dark backgrounds, negatively impacting keyboard accessibility. Adding descriptive metadata directly into array mapping objects (like `{ name: 'Instagram', icon: Instagram, href: '...' }`) provides an elegant way to dynamically generate accurate `aria-label`s for screen readers without cluttering visual design, and pairing it with explicit `focus-visible` offset ring classes guarantees keyboard users have clear visual feedback on dark themes.
**Action:** Always include a descriptive text property (e.g., `name` or `label`) inside data objects used for mapping interactive elements to effortlessly populate accessible names (`aria-label`). For dark-themed components, explicitly add robust `focus-visible` ring styling (e.g., `outline-none focus-visible:ring-2 focus-visible:ring-[color] focus-visible:ring-offset-2 focus-visible:ring-offset-[dark-bg-color]`) and apply `aria-hidden="true"` to purely decorative SVGs/icons.
