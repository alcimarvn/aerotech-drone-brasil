## 2026-07-13 - Accessible Footer Improvements
**Learning:** When mapping over objects to generate icon-only links (like social media links) or when creating compact embedded forms (like newsletter signups), it is extremely easy to miss accessible names, leading to WCAG 4.1.2 violations and a poor screen reader experience. Explicitly adding `aria-label` bound to object properties, pairing inputs with `sr-only` labels, explicitly hiding decorative SVG icons with `aria-hidden="true"`, and ensuring explicit focus styles for keyboard users improves usability dramatically.
**Action:** Always include a descriptive property like `name` in configuration arrays that render icon-only interactive elements to serve as dynamic `aria-label`s. Use `sr-only` labels with `htmlFor` for visually label-less inputs, explicitly hide nested SVGs from screen readers, and add `focus-visible` utility classes for clear keyboard navigation.
