## 2024-11-20 - Dark Theme Forms and Interactive Elements Accessibility
**Learning:** Default browser focus rings often lack sufficient contrast on dark backgrounds (like the dark green/black gradient in the footer). Additionally, mapping over arrays for icon-only buttons requires adding a specific descriptive property (like `name`) to dynamically generate `aria-label`s, as the icon components themselves do not carry accessible text.
**Action:** Always provide explicit, high-contrast `focus-visible` styles with appropriate offsets (`focus-visible:ring-offset-[#0a1a15]`) for elements on dark backgrounds. Ensure mapping arrays for icons include explicit string names to bind to `aria-label`, and always apply `aria-hidden="true"` to the decorative icon component itself. Use visually hidden `<label>` tags with `sr-only` for inputs instead of relying purely on placeholders.
