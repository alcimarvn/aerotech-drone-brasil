## 2024-07-08 - Dashboard Header ARIA Labels
**Learning:** For Next.js projects using Radix UI/Lucide React, it's essential to add `aria-hidden="true"` to both the decorative SVG icons (like Lucide's `Search` or `Bell`) and purely visual HTML elements like notification badge dots. This is particularly important when adding an `aria-label` to their parent `Button` or container to prevent screen readers from redundantly announcing the icons or reading them incorrectly. Radix `Avatar` requires its own `aria-hidden` attribute to stop screen readers when the parent `DropdownMenuTrigger` has the main `aria-label`.
**Action:** Always pair `aria-label` on the parent interactive element with `aria-hidden="true"` on all child decorative icons and purely visual elements (like dots/badges).
