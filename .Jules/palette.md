## 2024-09-06 - Dynamic ARIA Labels for Responsive User Account Elements
**Learning:** When adding `aria-label` to interactive elements (like the user dropdown button) that dynamically render visible text (like the user's name), or when responsive styling hides that text on smaller screens (turning them into icon-only buttons), the accessible name MUST include the visible text dynamically to prevent WCAG 2.5.3 (Label in Name) violations. Simply labeling it "User Menu" when the screen displays the user's name can cause voice dictation failures.
**Action:** Ensure that dynamic `aria-label` properties match the dynamic visible text inside (e.g., `aria-label={\`Menu de conta: \${session?.user?.name || "Usuário"}\`}`). Hide the inner visible DOM element from screen readers using `aria-hidden="true"` to avoid redundant announcements.
