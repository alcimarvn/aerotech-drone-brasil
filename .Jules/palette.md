## 2024-10-27 - Accessible Forms and Icon Buttons in Dark Themes
**Learning:** Decorative icons (like social media logos) and icon-only submit buttons (like the newsletter send button) often lack an accessible name for screen readers, and dark-themed components require explicit focus ring styling with appropriate offsets because default browser outlines often lack contrast against dark backgrounds. Inputs must have an associated `<label>`, which can be visually hidden but must remain accessible to screen readers using classes like Tailwind's `sr-only`.
**Action:** When adding accessible names (`aria-label`) to interactive elements, include the visible text dynamically if needed. Ensure purely visual HTML elements or decorative SVGs (e.g., Lucide React icons) have `aria-hidden="true"`. Apply appropriate `focus-visible:ring-2`, `focus-visible:ring-offset-2` to components, explicitly setting colors based on the theme (e.g. `focus-visible:ring-offset-[#0f231d]` for the footer).
