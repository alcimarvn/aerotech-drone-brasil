## 2024-10-27 - Icon-only buttons and dark mode focus visibility
**Learning:** Icon-only interactive elements (like social links and newsletter submit buttons) often lack accessible names, leading to poor screen reader experiences. Furthermore, default browser focus outlines are frequently invisible or have extremely poor contrast on dark-themed components (like a dark footer).
**Action:** When working on dark-themed components, always define explicit keyboard focus rings using `focus-visible:outline-none focus-visible:ring-2 focus-visible:ring-[color] focus-visible:ring-offset-2 focus-visible:ring-offset-[dark-bg-color]`. For arrays mapped into icon-only links, include a descriptive `name` property in the data array to dynamically populate `aria-label` and `title` attributes on the interactive element, while applying `aria-hidden="true"` to the decorative icon component itself.
