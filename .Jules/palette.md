## 2024-05-24 - Accessible Icon-Only Interactions on Dark Backgrounds
**Learning:** When mapping over arrays to render icon-only links (like social media icons) or using standalone icons for buttons (like a mobile menu), omitting an accessible name (`aria-label`) causes screen readers to either announce the URL or nothing at all, creating a poor experience for assistive tech users. Additionally, on dark-themed sections, default browser focus rings often lack contrast, making keyboard navigation difficult to track.
**Action:** Always include a descriptive `name` property in array mappings to dynamically generate `aria-label` and `title` attributes for interactive elements. Explicitly hide decorative inner SVGs using `aria-hidden="true"`. Apply explicit `focus-visible` styles with sufficient offset and contrast (e.g., `focus-visible:ring-emerald-500 focus-visible:ring-offset-[#0a1a15]`) on dark backgrounds.
