## 2025-02-28 - Dynamic ARIA Labels for User Menus
**Learning:** When applying WCAG 2.5.3 (Label in Name) to stateful buttons or complex interactive components like user profile menus that render dynamic visible text (e.g., the user's name), the `aria-label` must explicitly include that exact visible text to match screen reader announcements with visual expectations and voice command navigation. If a user menu displays "Menu John", the `aria-label` must also contain "John". Additionally, marking inner text/icons with `aria-hidden="true"` prevents screen readers from redundantly announcing both the container's `aria-label` and the inner text sequentially.
**Action:** Always interpolate dynamic visible data into the `aria-label` attribute for composite elements, and wrap inner content with `aria-hidden="true"` when the label provides a full text equivalent.
