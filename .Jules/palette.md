## 2024-05-24 - Accessible Icon-Only Links on Dark Backgrounds
**Learning:** Icon-only navigation links (like social media icons) can be inaccessible if they lack both a semantic `aria-label` for screen readers and a visible `title` tooltip for sighted users. Additionally, on dark gradients or complex backgrounds, the browser's default focus outline often has insufficient contrast or fails to appear entirely, rendering the links inaccessible to keyboard navigators.
**Action:** When creating icon-only buttons/links, dynamically assign a meaningful `aria-label` and `title` attribute. Furthermore, always specify explicit, high-contrast focus rings using Tailwind utilities (e.g., `outline-none focus-visible:ring-2 focus-visible:ring-emerald-500 focus-visible:ring-offset-2 focus-visible:ring-offset-[#0a1a15]`) to ensure the focus state is clearly visible against dark backgrounds. Add `aria-hidden="true"` to the inner decorative icon SVG.
