## 2026-09-30 - Custom Focus Rings on Dark Backgrounds
**Learning:** Default browser focus rings (e.g., standard outlines) often have insufficient contrast or fail to render clearly against very dark backgrounds like gradients used in the footer (#0a1a15). Screen reader users also require dynamic context for mapped social icons, rather than generic names.
**Action:** Always apply explicit focus utility classes tailored for dark modes (e.g., `focus-visible:ring-2 focus-visible:ring-emerald-500 focus-visible:ring-offset-2 focus-visible:ring-offset-[#0a1a15]`) to interactive elements. Furthermore, include a descriptive `name` field in mapped object arrays to dynamically generate `aria-label` and `title` values, ensuring context and passing label requirements while hiding the decorative SVG with `aria-hidden='true'`.
