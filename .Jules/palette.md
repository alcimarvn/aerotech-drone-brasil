## 2023-10-27 - Accessible Collapsible Sidebars
**Learning:** When building collapsible sidebars where navigation items shrink to icon-only variants, setting `aria-hidden="true"` on the icons and dynamically binding `title` and `aria-label` to the visible state ensures that screen readers and visual users (via tooltips) still receive context without redundant announcements when expanded. Radix UI primitives might handle `aria-expanded` internally, but standard custom toggle buttons still require explicit `aria-expanded` and `aria-label` attribute binding based on their open/closed state.
**Action:** Consistently use dynamic bindings for `title` and `aria-label` tied to the collapse state for icon-only navigation buttons, and ensure decorative icons within interactive elements always have `aria-hidden="true"`.
