## 2024-06-25 - Missing Accessible Names on Icon-Only Buttons
**Learning:** A recurring pattern in this codebase is the use of icon-only interactive elements (like the mobile menu button in the header or social links in the footer) without explicitly defining accessible names (`aria-label`) or hiding decorative SVGs from screen readers (`aria-hidden="true"`). This causes screen readers to either read generic element names (e.g., "button") or read out the SVG paths directly.
**Action:** When creating or fixing icon-only buttons, always ensure an `aria-label` is applied to the interactive parent element and `aria-hidden="true"` is applied to the nested decorative SVG (e.g., Lucide React icons) to provide clear context for screen reader users without redundant announcements.
