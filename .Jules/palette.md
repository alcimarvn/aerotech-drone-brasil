## 2024-05-24 - Dynamic Accessible Names on Iterated Icons
**Learning:** When mapping arrays containing purely decorative UI components or links to external urls, such as arrays for rendering icon-only social media elements, adding an accessible string name to each map object provides a simple way to dynamically assign `aria-label` and `title` to the interactive component (`<Link>` or `<button>`) while keeping `aria-hidden="true"` on the decoration (the icon component itself), ensuring accurate interpretation for screen readers and tooltips without creating separate explicit DOM elements for text.
**Action:** Always include string `name` properties within iterated generic arrays that power icon-only interactive UI arrays, and dynamically bind them to the mapping callback component using `aria-label` and `title`, applying `aria-hidden="true"` to the internal child SVG icon.
