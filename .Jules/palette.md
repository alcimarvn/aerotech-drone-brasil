## 2024-05-24 - Accessible Collapsible Sidebars
**Learning:** When creating collapsible UI elements (like sidebars) that reduce navigation items to icon-only buttons, conditionally unmounting the text removes the accessible name for screen readers, leading to poor accessibility. Additionally, default browser focus rings often lack sufficient contrast on dark backgrounds.
**Action:** Use a conditionally applied `sr-only` class to preserve the accessible name for screen readers while hiding it visually. Dynamically bind the `title` attribute to provide visual tooltips on hover. Ensure decorative icons have `aria-hidden="true"`. Apply explicit `focus-visible` ring styling with appropriate offsets (e.g., `outline-none focus-visible:ring-2 focus-visible:ring-emerald-500 focus-visible:ring-offset-2 focus-visible:ring-offset-slate-900`) for clear keyboard navigation on dark themes.
