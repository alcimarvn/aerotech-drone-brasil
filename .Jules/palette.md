## 2025-06-21 - Collapsible Sidebar Accessibility
**Learning:** Collapsible sidebars that reduce navigation items to icon-only buttons remove the visible text label, which severely degrades usability for screen reader users and creates ambiguity for sighted users without tooltips. Additionally, the toggle button itself requires its state to be communicated. Decorative icons inside these items must be hidden to prevent redundant or confusing screen reader announcements.
**Action:** When implementing or modifying collapsible sidebars, always dynamically bind `title` (for visual tooltips) and `aria-label` (for screen readers) based on the collapsed state. Provide an explicit `aria-expanded` state to the toggle button, ensure all interactive elements have visible focus styles (e.g., `focus-visible:ring-2`), and set `aria-hidden="true"` on the purely decorative internal icons.
