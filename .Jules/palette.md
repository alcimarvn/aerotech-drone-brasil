## 2026-10-07 - Dynamic Accessibility Properties in Mapped Arrays
**Learning:** When generating interactive components (like social links or icon buttons) from an array, mapping purely decorative or static configurations (like `{ icon: Facebook, href: '#' }`) prevents the assignment of specific, localized accessible names. Adding descriptive `name` properties directly into the source array ensures dynamic, precise `aria-label` and `title` assignments without hardcoding or brittle indices. Additionally, browser default outlines often lack contrast against dark-themed backgrounds; applying explicit focus ring utilities (e.g., `focus-visible:ring-emerald-500` with offsets) is essential for keyboard accessibility.
**Action:** Always include textual descriptors when configuring arrays for mapped interactive elements, and pair `focus-visible` utility classes with dark UI components to ensure visible tab focus.
