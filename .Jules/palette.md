## 2026-04-14 - Focus visibility on dark themed components\n**Learning:** In this project, interactive elements against dark backgrounds (like the footer gradient from #0a1a15 to #050c0a) completely lose default browser focus outlines. \n**Action:** Always explicitly define 'focus-visible:ring-2 focus-visible:ring-emerald-500' (or similar contrasting colors from the palette) on dark-themed actionable items to ensure keyboard navigation accessibility.
