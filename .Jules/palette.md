## 2026-08-21 - Dynamic aria-label for icon mapping & Explicit dark-theme focus rings\n**Learning:** When using map() to render icon-only buttons or links, adding a `name` property to the array objects allows dynamic and descriptive `aria-label` generation for screen readers while hiding the decorative icons via `aria-hidden=true`. Additionally, dark-themed interfaces require explicit `focus-visible` utility classes (e.g., `focus-visible:ring-emerald-500 focus-visible:ring-offset-[#0a1a15]`) because default browser outlines often lack contrast.\n**Action:** Always verify keyboard focus visibility on dark components, apply custom offset colors to match backgrounds, and ensure dynamic mappings include data fields specifically for accessible names.
