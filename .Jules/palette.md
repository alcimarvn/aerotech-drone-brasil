## 2024-10-03 - Accessible Tooltips for Dynamic Array Mappings
**Learning:** When mapping over dynamic arrays to render icon-only buttons or links (like social media elements), relying on a generic class or loop index is insufficient for accessibility. Responsive design constraints often convert text links to icon-only buttons on smaller screens, hiding context. Furthermore, `aria-label` provides an accessible name for screen readers, but sighted keyboard and mouse users lack context without a visible tooltip. Default focus rings often have poor contrast against dark themes.
**Action:** When mapping over arrays for icon-only elements, always add a descriptive `name` property to the array objects. Use this `name` to dynamically populate both `aria-label` and `title` attributes. Combine this with `aria-hidden="true"` on the purely decorative SVG icon to prevent redundant screen reader announcements. Finally, always provide explicitly colored `focus-visible` ring utility classes with an appropriate `ring-offset` that matches the background color for clear keyboard navigation visibility.
