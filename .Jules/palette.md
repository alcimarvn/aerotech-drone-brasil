## 2026-09-22 - Accessible Collapsible Sidebars
**Learning:** When building collapsible navigation sidebars, do not conditionally unmount text labels (e.g., `{!isCollapsed && <span>...</span>}`). This removes the accessible name for screen readers when collapsed. Instead, always render the text and conditionally apply a visually hidden class (e.g., `sr-only`). Additionally, provide `title` attributes on the container for visual tooltips, apply `aria-hidden="true"` on decorative icons to prevent redundant announcements, and use explicit `focus-visible` rings with offsets since default browser outlines often fail color contrast checks on dark mode backgrounds.
**Action:** Always use `sr-only` instead of unmounting for hidden structural text, and explicitly define focus rings on dark-themed interactive elements.
