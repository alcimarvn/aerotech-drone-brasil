## 2026-10-11 - Adding Accessible Names to Mapped Icon-Only Links and Embedded Form Elements
**Learning:** When mapping over objects to render icon-only links (e.g. social media buttons), adding a discrete descriptive property like `name` to the array objects enables dynamic generation of robust `aria-label` and `title` attributes. Similarly, embedded form inputs like newsletters often lack space for a visual label, necessitating a visually hidden label (e.g. `sr-only`) explicitly linked to the input via `id`, along with comprehensive ARIA roles on submit buttons to maintain WCAG standards.
**Action:** Always include a descriptive property within data arrays used for mapped iterative interactive elements to support screen readers, and employ `sr-only` tags for explicitly connected labels when visual labels disrupt the design.
