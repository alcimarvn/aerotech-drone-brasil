## 2024-09-07 - Accessible Icon-Only Interactive Elements
**Learning:** In Next.js/React applications, when mapping over arrays to render icon-only interactive elements (like social media links in footers) or adding mobile menu triggers, omitting accessible names breaks keyboard and screen reader navigation. Dark-themed components often fail WCAG contrast guidelines for standard browser focus rings.
**Action:** Always include a `name` property in link/button arrays to generate dynamic `aria-label` and `title` attributes. Explicitly add `aria-hidden="true"` to decorative icons (like Lucide React SVG elements) within these interactive containers to prevent redundant announcements. Apply explicit `focus-visible` styling with sufficient offset (e.g., `focus-visible:ring-offset-2 focus-visible:ring-offset-[dark-bg-color]`) to guarantee keyboard focus visibility on dark backgrounds.
