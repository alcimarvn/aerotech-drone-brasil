## 2026-05-22 - Accessibility Improvements in Dashboard Header\n**Learning:** When dealing with responsive components that hide text visually on smaller screens (like user menus), the button can unintentionally become an icon-only button lacking an accessible name for screen readers. Explicit `aria-label`s and hiding internal redundant elements (`aria-hidden="true"`) are required.\n**Action:** Always check responsive states for buttons that rely on text visibility; if text is hidden, an `aria-label` should be bound to the container.
