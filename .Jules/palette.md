## 2024-03-24 - Accessible Collapsible Sidebars
**Learning:** When collapsing navigation menus (like sidebars) to icon-only views, conditionally rendering the text label (e.g., `{!isCollapsed && <span>Label</span>}`) completely removes the accessible name for screen readers, leading to unlabelled button/link announcements.
**Action:** Instead of unmounting the text conditionally, use a visually-hidden class (like Tailwind's `sr-only`) when collapsed (e.g., `<span className={cn("font-medium", isCollapsed && "sr-only")}>Label</span>`). Combine this with `aria-hidden="true"` on the icons and native `title` attributes on the parent to provide both screen reader accessibility and visual tooltips for sighted users. Ensure the expand/collapse toggle uses `aria-expanded` and explicit `focus-visible` styling.
