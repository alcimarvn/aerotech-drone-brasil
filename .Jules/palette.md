## 2024-09-08 - Accessible Names for Mapped Icon-Only Links and Dark Theme Focus Rings
**Learning:** When generating icon-only links via a map function (e.g., social media icons), adding a descriptive `name` property to the mapped array objects is crucial for dynamically creating accessible `aria-label` and `title` attributes. Furthermore, in dark-themed applications, default browser focus rings often lack contrast. Custom focus rings using Tailwind utilities (`focus-visible:ring-2 focus-visible:ring-emerald-500 focus-visible:ring-offset-2 focus-visible:ring-offset-[#0a1a15]`) are required for proper keyboard accessibility visibility, and `aria-hidden="true"` should always be applied to decorative SVG icons within interactive elements.
**Action:** Always include a descriptive `name` in data arrays for mapped interactive elements, explicitly apply custom high-contrast focus rings for dark modes, and hide purely decorative child icons from screen readers using `aria-hidden="true"`.
