## 2024-08-15 - Mapped Icon-Only Links and Dark Theme Focus States
**Learning:** When mapping over an array to render icon-only links or buttons, adding a descriptive `name` property to each object in the array enables the dynamic generation of accessible `aria-label`s. Furthermore, dark-themed components often have inadequate default browser focus outlines.
**Action:** Always include a `name` property for dynamically mapped icon-only elements to bind to `aria-label`. Additionally, apply explicit focus ring classes with offsets (e.g., `focus-visible:outline-none focus-visible:ring-2 focus-visible:ring-white focus-visible:ring-offset-2 focus-visible:ring-offset-slate-900`) for interactive elements on dark backgrounds to ensure keyboard navigation is visible and accessible. Hide purely decorative icons from screen readers using `aria-hidden="true"`.
