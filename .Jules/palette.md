## 2024-05-24 - Dynamic ARIA Labeling and Dark Mode Focus Rings in Mapped Components
**Learning:** When mapping over generic arrays to create icon-only interactive elements (like social links), it's highly effective to inject a descriptive string (like `name`) into the source array to serve as a dynamic `aria-label` and `title`. Additionally, default browser focus rings fail on dark gradients; explicit `focus-visible:ring-offset-[#0a1a15]` or similar background-matching offsets are critical for keyboard navigation visibility.
**Action:** Always include string identifiers for accessible naming when creating data arrays for icon-only components. Apply explicit, high-contrast `focus-visible` utility rings with appropriate offsets when styling elements against dark or gradient backgrounds in this project.
