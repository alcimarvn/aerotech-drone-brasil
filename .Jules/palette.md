## 2024-05-24 - Accessibility improvements for Footer components in Dark Mode
**Learning:** Default browser focus outlines often lack contrast or are entirely invisible against dark backgrounds like `#0a1a15`. Additionally, visually hidden inputs in forms need semantic linkages, and dynamically rendered arrays for social links need explicit names bound to their objects to build accurate ARIA labels to maintain screen reader accessibility.
**Action:** When creating dark-themed components, apply explicit focus ring styling with appropriate offsets (e.g., `outline-none focus-visible:ring-2 focus-visible:ring-emerald-500 focus-visible:ring-offset-2 focus-visible:ring-offset-[#0a1a15]`). When rendering icon-only buttons via an array mapping, include a `name` property inside the array to dynamically bind `aria-label` and `title` to the anchor tags. Always associate inputs lacking visual labels with a visually hidden `<label>` via `htmlFor` and `id`, and explicitly set `aria-hidden="true"` on decorative icons inside interactive elements to prevent redundant screen reader announcements.
