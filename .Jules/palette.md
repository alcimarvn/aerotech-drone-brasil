## 2024-11-08 - Accessible Header Search and Notifications
**Learning:** The dashboard header contained multiple interactive elements (search input, notification bell, user dropdown) missing proper ARIA labels. Radix UI/Tailwind components often embed decorative SVG icons (like Lucide's `Search`, `Bell`, `User`) and visual badges (red notification dot) that are incorrectly announced by screen readers if not explicitly hidden.
**Action:** Always add `aria-label` to interactive inputs and icon-only buttons. Explicitly add `aria-hidden="true"` to nested decorative SVGs and purely visual HTML elements (like notification dots) within these buttons to prevent redundant screen reader announcements. Ensure focus rings (`focus-visible:ring-*`) are explicitly applied to icon-only buttons for keyboard users.
