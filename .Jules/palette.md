## 2024-06-27 - Preserving Accessible Names in Collapsible Navigation
**Learning:** When conditionally shrinking a sidebar to an icon-only mode, unmounting the text labels completely (e.g., `{!isCollapsed && <span>Label</span>}`) removes the accessible name for screen readers on those interactive elements, unless explicit `aria-label`s are added to each link.
**Action:** Instead of unmounting the text nodes, apply a conditional `sr-only` class to the span elements (e.g., `<span className={cn(isCollapsed && "sr-only")}>Label</span>`). This visually hides the text while preserving the accessible name natively, avoiding redundant `aria-label` additions. Additionally, dynamically binding a `title` attribute for visual tooltips and applying explicit focus indicators (`focus-visible`) improves both accessibility and keyboard UX.
